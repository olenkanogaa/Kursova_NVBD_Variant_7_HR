# Kursova_NVBD_Variant_7_HR

Курсова робота з дисципліни "Надвеликі бази даних"
Тема: Розробка та аналіз надвеликої бази даних для системи "Облік кадрів"

Варіант №7 

Студентка: Нога О.В.
Група: ПМ-41
Викладач: Любінський Б.Б. 

 Опис проєкту
Метою роботи є розробка повнофункціональної системи керування надвеликою базою даних для автоматизації процесів відділу кадрів. Проект включає реалізацію OLTP-системи, розробку ETL-процесів, побудову OLAP-куба для аналітики та створення інтерактивних звітів.


Предметна область: Облік працівників, відділів, посад, відпусток та історії кадрових змін.

 Технологічний стек

DBMS: Microsoft SQL Server 


ETL: SQL Server Integration Services (SSIS) 

Analytics: SQL Server Analysis Services (SSAS) — Multidimensional Mode 


Reporting: SQL Server Reporting Services (SSRS) 

Data Generation: [Вказати інструмент, напр. Python/SQL Script/Redgate] 

 Структура репозиторію
Згідно з вимогами до курсової роботи, проєкт організовано наступним чином:


/Database — SQL-скрипти для створення структури БД, обмежень, тригерів та процедур.


/DataGeneration — скрипти та інструменти для генерації понад 500 000 записів.


/SSIS_Projects — пакети інтеграції для завантаження даних у Data Warehouse.


/SSAS_Projects — проєкт OLAP-куба з вимірами та мірами.


/SSRS_Projects — аналітичні звіти (таблиці, матриці, дашборди).


/Documentation — пояснювальна записка у форматі PDF.

 Основні показники бази даних

Кількість працівників: > 10 000 записів.


Кількість записів про відпустки: > 100 000 записів.


Глибина історії: 20 років.


Загальний обсяг фактів: понад 500 000 записів.

 Реалізовані аналітичні звіти (SSRS)
У проекті реалізовано 5 обов'язкових звітів:


Список працівників відділу — табличний звіт з групуванням.


Використання відпусток — звіт з підсумками та агрегацією.


Довідка працівника — детальний звіт про посаду та оклад.


Список відділів з керівниками — ієрархічний звіт.


Аналіз плинності кадрів — аналітичний звіт з візуалізацією динаміки.


 Як запустити проєкт

База даних: Виконати скрипти з папки /Database у SQL Server Management Studio.


ETL: Відкрити проект у Visual Studio (SSDT), налаштувати Connection Managers та запустити пакети SSIS.


OLAP: Розгорнути (Deploy) проєкт SSAS для створення куба.

Звіти: Налаштувати Shared Data Source у проекті SSRS та опублікувати звіти на Report Server.
